# Patrick OS — AI Command Centre

Public-safe, zero-cost, standalone mobile miniature prototype.

## Demo

Open `index.html` in a browser or publish via GitHub Pages. The interactive CSS 3D miniature, six clickable departments, agent selectors, simulated task progression, and activity log use no external JavaScript dependencies.

**Every task, log and agent action is simulated. There is no live GitHub, Codex or production integration.**

## Enable GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Once GitHub reports a successful deployment, visit:

https://patricktbann.github.io/Patrick-OS-Command-Centre/
